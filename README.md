# EreVanton

Site estático (HTML + CSS + JS), sem build.

## Estrutura

```
index.html
assets/
  style.css
  page.js
  *.webp
```

## Deploy na Vercel

1. Suba esta pasta para um repositório no GitHub (o `index.html` precisa ficar na raiz do repositório).
2. Na Vercel: Add New > Project > importe o repositório.
3. Framework Preset: **Other**. Build Command e Output Directory: deixe vazio.
4. Deploy.
